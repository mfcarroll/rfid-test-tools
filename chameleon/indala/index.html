Chameleon Ultra Indala test

Time how fast your Chameleon Ultra reads an Indala card, or how fast a Flipper Zero reads the CU's Indala emulation. To compare firmwares, flash a different one between runs without moving anything. The page is made for testing PR #509.

Lay the card flat on the CU's button side (the antenna is on that side, not the LED side). The CU reads the card a set number of times, and records how long each read takes. The card most reads return counts as the card, and a read that returns any other card counts as wrong. The results never show the actual credential.

  1. Lay the Flipper's back on the CU's button side. Leave both where they are for every run, including after flashing other firmware.
  2. Pick a slot for the test card. Start replaces that slot's LF card with an Indala test card (FC 123, card 1337) and makes the slot active. The Flipper then reads the test card. The CU's white light comes on while the Flipper reads.

Options

The page determines the Indala commands from the firmware. Change them only if the page gets them wrong.

Firmware

Flashing replaces the CU's firmware and keeps its slots. To compare firmwares, flash here between runs without moving the CU or the Flipper, then connect again.

"Flash a file" takes an application DFU package (a .zip), such as a nieldk release.

Results

Each run adds a row. The Copy button copies the table to the clipboard as Markdown, ready to paste into a GitHub comment.

A fingerprint is the first 4 hex digits of the SHA-256 of the frame the CU read. It shows whether two runs read the same card (your card and its T5577 clone, say) without showing the card. It doesn't hide the card completely. An Indala 26-bit card has about 16 million possible values, and a fingerprint has 65,536, so one fingerprint matches about 256 possible cards. If that's too much to post, untick Include card fingerprints. The table's wrong-read count works without fingerprints.

Crystal offsets

How long a Flipper takes to read an emulation can depend on how far apart the CU's and the Flipper's crystals run. Measure each on its own page: Chameleon Ultra and Flipper Zero. The CU's page flashes its own test firmware and then stock firmware. Run the tests on this page first.
