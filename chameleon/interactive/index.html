Chameleon Ultra interactive LF emulation (experimental)

Emulate an interactive LF tag — one that answers a reader's commands, not just a fixed card number. The first one is Hitag 2 in password mode. Set up a test tag, take the CU to your reader, and the page tells you whether the reader engaged with it and how far the exchange got.

Everything happens in this browser. The page talks to the CU over USB. Nothing is sent to any server, and it doesn't save anything unless you press Copy or Download.

This is a made-up test tag, not a real credential. Its UID is yours to set; its password is a fixed placeholder. A reader won't open anything with it — the point is to see whether the reader treats the CU as a Hitag 2 tag at all.

Connect the Chameleon Ultra

This page requires Chrome or Edge on a computer. Use USB, not Bluetooth, and close anything else using the CU, such as the CU app or the Python CLI.

Checking the firmware…

This firmware has no interactive LF engine. Flash the experimental firmware below, then connect again.

1. Set up a Hitag 2 test tag

Puts a Hitag 2 test tag in the active slot and saves it. Set the UID to your fob's if you want the reader to see that number; the password stays a placeholder.

2. Clear the trace, then go to the reader

Clear the trace, unplug the CU, and hold it to the reader. The trace survives the CU's sleep, so you can read it back here afterwards. Each wake is a new boot in the report.

3. Read the trace

Back at the computer, connect again and read what the reader did.

Firmware

Needs the experimental firmware: the interactive LF engine with the Hitag 2 module (source). Flashing replaces the CU's firmware and keeps the current slots.
